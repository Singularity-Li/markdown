# Markdown 1.2.0

- 新增启动时自动检查 GitHub 新版本，以及菜单栏“检查更新…”入口。
- 支持一键下载、验签、安装并重启，保留未保存文档确认。
- 新增签名更新包与更新清单验证，防止下载损坏或内容被篡改。
- 保留半透明玻璃背景的双色 MD 图标及更新后的图标刷新机制。
- 新增 Agent 发布入口：直接说“发布新版本”即可按工程规范完成正式发布。

这是首个支持 App 内更新的版本。此前版本需先手动安装本版，后续可直接在 App 中升级。

点击安装更新后将自动下载、验证并重启；未保存内容会先提示保存。
需要 macOS 26 或更新版本及 Apple Silicon。
