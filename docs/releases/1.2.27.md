# Markdown 1.2.27

### 新功能

- 加入可视化 Markdown 编辑器，标题、列表、复选框、表格、图片和代码块可直接排版编辑；保留源码编辑与预览。
- 输入 `/` 打开分类插入菜单，支持中文、拼音和拼音首字母筛选，并可用方向键、回车完成选择。
- 工具栏统一为“源码 / 可视化 / 预览”三种模式；按 `⌘R` 按顺序循环切换。
- 可视化编辑中的代码块可独立切换深浅配色；编辑和预览中的代码块均可一键复制带语法颜色的富文本，同时保留纯文本。

### 其他改进

- 更新中英文功能说明与截图，并完善开源许可和第三方依赖声明。

点击安装更新后将自动下载、验证并重启；未保存内容会先提示保存。
需要 macOS 26 或更新版本及 Apple Silicon。
