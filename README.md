# Markdown

适用于 macOS 26 及以上的原生 Markdown 阅读与编辑应用。

- 全窗透明背景，使用系统 Liquid Glass 与桌面背景模糊。
- 支持文件、文件夹、拖放、离线 Markdown 渲染及代码高亮。
- 支持同目录及子目录图片、标题锚点；网页链接在默认浏览器打开。
- 切换文档、打开文件夹和退出前保护未保存内容；读写失败显示错误。

## 构建与验证

```sh
bash scripts/test.sh
bash scripts/build_app.sh
```

构建前退出桌面正在运行的 Markdown。构建脚本生成并签名应用，完整替换仓库根目录的 `Markdown.app`，并同步部署到 `~/Desktop/Markdown.app`，不会覆盖已有示例文件。生成后可双击应用运行。

快捷键：`⌘O` 打开文件或文件夹、`⌘S` 保存、`⇧⌘P` 切换预览与编辑。

## 验证范围

回归检查覆盖文件选择同步、读取失败保留文档、不支持的类型、应用程序包、取消文档/目录切换、保存后重开、撤销恢复保存状态和符号链接循环。桌面示例已用于实际检查图片、锚点、预览/编辑、退出取消、撤销及错误提示。

启动和单文件模式默认隐藏侧栏。通过统一打开入口或拖放打开文件夹时，侧栏自动展开；标题旁的侧栏按钮可随时收起或再次展开。

## 开发交付规范

每次完成开发，先验证并编译最新 App，再将源码与根目录 `Markdown.app` 一起提交、推送到远程。完整规范见 [AGENTS.md](AGENTS.md)。

若桌面 App 正在使用，可运行 `DEPLOY_DESKTOP=0 bash scripts/build_app.sh`，仅更新仓库根目录产物。构建缓存和备份不会纳入 Git。

每次交付同时维护 `.gitignore`：忽略缓存、日志、临时产物、截图、备份和个人环境文件，保留必要资源、开发文档及根目录 App。
