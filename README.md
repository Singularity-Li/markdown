# Markdown

适用于 macOS 26 及以上的原生 Markdown 阅读与编辑应用。

- 全窗透明背景，使用系统 Liquid Glass 与桌面背景模糊。
- 支持文件、文件夹、拖放、离线 Markdown 渲染及代码高亮。
- 支持同目录及子目录图片、标题锚点；网页链接在默认浏览器打开。
- 顶部标签页同时打开多份文档，支持文件多选和批量拖放；重复打开自动定位已有标签。
- 每个标签独立保留正文、预览/编辑模式和未保存状态；关闭标签或退出时提示保存，读写失败显示错误。

## 构建与验证

```sh
bash scripts/test.sh
bash scripts/build_app.sh
```

构建前退出桌面正在运行的 Markdown。构建脚本生成并签名应用，完整替换仓库根目录的 `Markdown.app`，并同步部署到 `~/Desktop/Markdown.app`，不会覆盖已有示例文件。生成后可双击应用运行。

快捷键：`⌘O` 打开文件或文件夹、`⌘S` 保存当前标签、`⌘W` 关闭当前标签、`⇧⌘P` 切换预览与编辑。

## 验证范围

回归检查覆盖多文件打开与去重、标签状态隔离、正确保存到对应文件、关闭与取消关闭、退出检查后台草稿、保存失败保护、目录导航及不支持格式占位。已实际验证多选打开、标签切换、保存和关闭、统一工具栏布局、页内格式提示，以及模式文字和颜色。

启动和直接打开文件时默认隐藏侧栏。通过统一打开入口或拖放打开文件夹时，侧栏自动展开；标题旁的侧栏按钮可随时收起或再次展开。

## 开发交付规范

每次完成开发，先验证并编译最新 App，再将源码与根目录 `Markdown.app` 一起提交、推送到远程。完整规范见 [AGENTS.md](AGENTS.md)。

若桌面 App 正在使用，可运行 `DEPLOY_DESKTOP=0 bash scripts/build_app.sh`，仅更新仓库根目录产物。构建缓存和备份不会纳入 Git。

每次交付同时维护 `.gitignore`：忽略缓存、日志、临时产物、截图、备份和个人环境文件，保留必要资源、开发文档及根目录 App。

多文件标签：点击顶部文件名切换，点击标签右侧 × 关闭。未保存标签显示圆点；标签较多时可横向滚动。打开目录保留已有标签，关闭全部标签后仍可从目录选择文件。

工具栏和标签栏横跨整个窗口，目录分隔线仅出现在下方内容区。不支持的文件以内容区占位提示展示，不弹出警告，且不会替换已有 Markdown 标签或修改原文件。

模式开关随状态显示蓝色“预览”或橙色“编辑”，每个标签保留自己的模式。

“打开”左侧的玻璃按钮可调节窗口背景透明度：点击显示滑杆，点击空白处收起。背景实时变化，正文与控件不随之淡化；设置自动保存并在重启后恢复。

中英文等页内切换链接保留文档自定义的 HTML 锚点（如 `id="zh"`、`id="en"`），自动生成的标题锚点会避开已用名称。`Markdown示例.md` 含可点击的中文 / English 双向跳转；回归检查使用 WebKit 验证实际渲染后的锚点。
